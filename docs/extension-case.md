# 확장 사례: 가상의 사내 교육자료

강의 자료가 아닌 회사 안 교육자료에도 같은 방식이 통하는지 확인한 기록이다.

## 자료

- 이름: 「한빛물산 2026 하반기 신입사원 교육 · 업무용 AI 도구 사용 안내」 6장
- 회사와 부서는 지어낸 것이다. 실제 회사의 내부 자료나 개인정보는 쓰지 않았다.
- 내용은 공개된 공식 문서로 확인할 수 있는 도구 안내다(Google Antigravity, Gemini Notebook).
- 원본: `eval/company-deck.json`. PowerPoint 에서 열 수 있는 PPT 는 `node eval/build-company-deck.cjs` 로 만들어 `tests/fixtures/company-training-sample.pptx` 에 둔다. 문장은 원본과 한 글자도 다르지 않다.

## 일부러 심어 둔 것

정답은 2026-11-15에 공식 문서 본문에서 직접 확인했다.

| 장 | 자료에 적은 내용 | 정답 | 공식 문서(확인한 값) |
|---|---|---|---|
| 2 | 데스크톱 앱은 macOS 12(Monterey) 이상 | 바뀜 | macOS 13 (Ventura) or later |
| 2 | Windows 10(64비트)과 Windows 11 지원 | 그대로 | Windows 10 (64-bit) or Windows 11 |
| 2 | 앱 최신 버전은 2.28 | 바뀜 | v2.32.0 이 Latest |
| 3 | 개인 계정은 월 0달러 | 그대로 | For Individuals $0/month |
| 3 | Pro 사용량은 24시간마다 다시 채워짐 | 바뀜 | refreshed every five hours until the weekly limit is reached |
| 4 | 무료는 노트북 100개까지 | 그대로 | Notebooks 100/user |
| 4 | 무료는 노트북 하나에 자료 30개까지 | 바뀜 | All sources except notes 50/notebook |
| 5 | 플러그인은 Customizations 의 Marketplace 에서 추가 | 그대로 | Customizations > Marketplace |
| 5 | 마켓플레이스에 플러그인이 모두 60개 | 확인 못 함 | 공식 문서에 개수가 없다 |

낡은 정보 4개, 맞는 정보 4개, 공식 문서에 없는 정보 1개다. 5장의 사내 규정("고객 정보가 든 파일은 올리지 않아요" 등)은 공식 문서로 확인할 수 없는 내용이라 뽑히지 않아야 한다.

화면과 같은 흐름(추출 → 검색 → 본문 읽기 → 판정)으로 처음부터 끝까지 돌렸다.

| 항목 | 값 |
|---|---|

| 공식 문서에 없는 내용을 단정함 | 0번 |

어긋난 1번은 "Customizations 의 Marketplace 에서 추가"를 한 번 확인 못 함으로 본 것이다. 틀린 단정은 아니고, 근거를 못 찾아 사람에게 넘긴 경우다.

## 이 수치를 읽을 때 주의할 점

- 자료가 작다(심은 내용 9개). 그리고 검사기를 만든 쪽이 자료도 만들었다.
- 이 자료로 재면서 고친 부분이 있다. 처음 측정은 27번 중 22번 일치였고, 공식 사이트를 여러 곳 지정했을 때 한 곳만 검색하던 문제를 고친 뒤 24번, 자료의 모호한 문장을 고친 뒤 26번이 됐다.
- 세 번째 변화는 검사기가 아니라 자료를 고친 것이다. 처음에는 "macOS 12 이상에서 설치"라고만 적었는데, 공식 문서에 제품 형태에 따라 macOS 12+ 와 macOS 13+ 가 모두 있어서 정답이 하나로 정해지지 않았다. "데스크톱 앱"이라고 밝혀 적어 정답을 하나로 만들었다.
- 그러므로 이 수치는 "이 자료에서 이렇게 나왔다"는 뜻이고, 다른 자료에서도 같게 나온다는 보장은 아니다.

## 다시 재는 법

```bash
npm run dev                          # 워커를 로컬에서 켠다
node eval/run-deck-eval.js --runs 3  # 다른 터미널에서
```

공식 문서가 바뀌면 정답도 바뀐다(예: 최신 버전). 다시 잴 때는 위 표의 "공식 문서" 칸부터 다시 확인한다.
