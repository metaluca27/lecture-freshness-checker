# 데모 영상 대본 (5분 이내)

목표 길이는 4분 30초다. 실제 실행 화면만 쓰고, 결과를 꾸미지 않는다. 화면에 나온 숫자와 판정은 그날 실제로 나온 것을 그대로 말한다.

## 찍기 전에 준비할 것

- [ ] 브라우저를 **시크릿 창**으로 연다. 프로필 사진, 이메일, 즐겨찾기가 화면에 나오지 않게 한다.
- [ ] 주소창에 `https://vaulted-bus-346411.web.app/fresh` 를 미리 열어 둔다.
- [ ] 올릴 파일 두 개를 바탕화면의 빈 폴더에 둔다. 다른 파일 이름이 탐색기에 보이지 않게 한다.
  - 강의 자료: 안티그라비티 강의 **PPT**(발표 노트의 "지금 최신은 2.31.0" 이 잡히려면 PDF가 아니라 PPT여야 한다)
  - 가상 사내 자료: `tests/fixtures/` 의 한빛물산 자료
- [ ] 강의 자료 표지에 강사 이름이 있다. 대회 규정상 화면에 이름이 나오면 안 되므로, **표지의 이름을 지운 사본**으로 찍는다. 결과 화면 1쪽 왼쪽에도 표지 글자가 보인다.
- [ ] 찍기 직전에 한 번 돌려 본다. 공식 문서가 바뀌면 결과도 바뀐다. 대본의 숫자와 다르면 **화면에 나온 대로** 말한다.
- [ ] 화면 녹화는 1920×1080, 브라우저 확대 110~125%.
- [ ] 다 찍고 유튜브에 "일부 공개"로 올린 뒤, 시크릿 창에서 링크가 열리는지 확인한다.

## 말할 때 지킬 것

- 걸린 시간, 개수, 버전은 **화면에 나온 값**을 읽는다. 대본의 괄호 부분은 찍는 날 채운다.
- "50분쯤"은 제작자가 기억하는 시간이다. 시계로 잰 값처럼 말하지 않는다.
- 가상 자료의 측정 수치(열두 번 중 열두 번)는 2026-11-15 측정값이다. 찍는 날 `npm run eval` 로 다시 재서 달라졌으면 새 값을 말한다.
- "바뀜"이 하나도 안 나오면 연출하지 않는다. 그 경우 가상 사내 자료 장면을 앞으로 당긴다.
- 화면에 이메일, 사용자 이름, 다른 탭의 제목이 보이지 않는지 마지막에 한 번 돌려 본다.
